# docs/

- `edge-cases/`: Level 1 documentation of billing edge cases, meaning what each one is and why it matters. It does not describe how Sutyr responds to them.
- `screenshot.png`: suite mode on lab.sutyr.com (version 0.2.0, October 2026 brand) after a run against an endpoint that accepts anything. The project README shows it.

To replace the screenshot, capture `lab.sutyr.com` at 1440 by 900 in suite mode with a finished run in the results panel, crop the browser chrome, and save it as `screenshot.png` in this directory.
