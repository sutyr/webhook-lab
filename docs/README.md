# docs/

- `edge-cases/`: Level 1 documentation of billing edge cases, meaning what each one is and why it matters. It does not describe how Sutyr responds to them.
- `screenshot.png`: a capture of the 0.1.0 interface. It predates the suite, the new hierarchy and the October 2026 brand, so the project README does not show it.

To replace the screenshot, capture `lab.sutyr.com` (or `localhost:3000`) in suite mode with the three-panel layout visible and a finished run in the results panel, crop the browser chrome, and save it as `screenshot.png` in this directory. Then add it back to the top of the [README](../README.md).
